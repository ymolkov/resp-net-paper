Respiratory neurophysiology

From cellular synaptic input profiles to population-level respiratory circuitry

Yaroslav I. Molkov, Ilya A. Rybak, and Jeffrey C. Smith

Which brainstem populations supply the synaptic inputs that shape each phase of breathing? We compared when these populations fire with when individual neurons receive excitation and inhibition to reconstruct a candidate circuit.

Read the paper

The approach

How did we infer these connections?

Discharge patterns tell us when respiratory neurons fire. Synaptic conductances tell us when those neurons receive excitation and inhibition.

In pre-I/I neurons, for example, inhibition peaks near the start of expiration and then declines. To ask which populations could supply inputs with that timing, we compared conductance profiles from 150 cells with five independently recorded discharge patterns.

A

Reconstruct each cell’s inputs

For each neuron, we estimated how excitation and inhibition change over a respiratory cycle. We grouped neurons by when they fire.

B

Ask which sources are needed

We treated the same populations as possible sources. If we leave one out, can the others still reproduce the timing of the input across cells?

C

Assemble the circuit

A solid connection identifies a source the recordings distinguish. Dashed connections show alternatives: different sources can produce similar inputs.
